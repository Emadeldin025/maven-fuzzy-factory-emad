
# 📊 Phase 2: Website Measurement & Testing

## Overview
This phase examines how users behave once they arrive at the site. We evaluate landing page performance, funnel behavior, and conversion testing.

---

## 📷 Dashboard Preview

![Dashboard Preview](Website%20M&T.png)

## Key Analyses

### 🔹 Landing Page Performance
- Top entry pages by session volume
- Bounce rates for `/home` vs `/lander-1`

### 🔹 Bounce Rate Analysis
- `/home` had a bounce rate of ~59%
- `/lander-1` reduced bounce rate in A/B test

### 🔹 Funnel Click-through Analysis
- Step-by-step drop-off from landing page to order
- Each page transition's click-through rate

### 🔹 Billing Page Test
- Compared `/billing` vs `/billing-2`
- Conversion improved from ~46% to ~63%
